Credit Card and Bank Statement Consolidator - Help

Usage:
    python main.py --input <path_to_statement_files> --output <output_excel_file>

Options:
    --input         Path to input files (PDF, CSV, XLS)
    --output        Path to the consolidated Excel output
    --log-level     Set log verbosity [INFO, DEBUG]
    --dry-run       Run the parser without writing output

Supported Banks:
    - HDFC Bank
    - ICICI Bank
    - IndusInd Bank

Source Types:
    - CreditCard
    - Bank
